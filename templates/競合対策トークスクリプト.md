## 楽天証券ユーザーへの対応

### シーン1: 「楽天証券を使っているので十分です」

```
顧客:「楽天証券をもう使っているので、そちらで十分です。」

営業:「楽天証券も素晴らしい証券会社ですよね。
     実は私も個人的に使ったことがあります。

     ただ、一つだけ教えていただきたいのですが、
     クレカ積立のポイント還元率はご存知ですか？」

顧客:「えっと、楽天カードで1%くらいだったような...」

営業:「実は、楽天証券は2022年に制度が変わって、
     今は0.5-1.0%なんです。

     一方、SBI証券は三井住友カードで最大5.0%なんです。

     [資料を見せる]

     具体的に計算してみますね。
     ○○様は月いくら積み立てていらっしゃいますか？」

顧客:「月10万円くらいです。」

営業:「月10万円ですと、年間120万円ですね。

     楽天証券（1.0%）: 年間12,000円分のポイント
     SBI証券（5.0%）: 年間60,000円分のポイント

     差額: 年間48,000円分

     30年続けると、144万円の差になります。

     144万円あれば、
     ・世界一周旅行に行ける
     ・高級車が買える
     ・お孫さんの教育資金に

     実現できますよね。

     移行の手続きは簡単で、30分もあれば完了します。
     一度、詳しくご説明させていただけませんか？」

顧客:「そんなに違うんですか...」

営業:「はい。144万円は大きいですよね。

     しかも、SBI証券には他にもメリットがあります。

     [比較表を見せる]

     - IPO取扱No.1: 楽天より年間約30社多い
     - 外国株9カ国対応: 楽天は6カ国
     - ポイント選択肢5種類: 楽天は楽天ポイントのみ

     特にIPOは、1回の当選で40-50万円の利益も
     期待できます。

     ○○様、一度SBI証券も併用してみませんか？

     楽天証券も残しつつ、新規投資分だけSBI証券で
     始めてみて、使い比べてみるのはいかがでしょう？」

顧客:「併用できるんですか？」

営業:「はい、NISA口座は1人1口座ですが、
     今年から変更も可能ですし、
     一般の投資信託なら両方で持てます。

     まずは試してみて、気に入ったらNISA口座も
     移行するというのが安心です。

     いかがですか？」
```

## 対面証券ユーザーへの対応

### シーン3: 「野村證券でずっとお世話になっています」

```
顧客:「野村證券の担当者さんが親切で、
      ずっとお世話になっているんです。」

営業:「素晴らしいですね。良い担当者の方に
     出会えたのは財産です。

     ただ、一つ質問させてください。
     その担当者の方は、あと何年その仕事を
     続けられるでしょうか？」

顧客:「えっと...わかりませんね。」

営業:「担当者は異動や退職で変わることがあります。
     今の方がずっと担当してくれるとは限りません。

     一方、コストは確実に残り続けます。

     [資料を見せる]

     具体的に計算してみましょう。
     野村證券でいくら投資していらっしゃいますか？」

顧客:「月10万円くらいです。」

営業:「30年間、月10万円を投資した場合:

     【野村證券】
     - 購入時手数料（2%）: 72万円
     - 信託報酬（1.0%）: 約360万円
     - 合計: 約432万円

     【SBI証券】
     - 購入時手数料: 0円
     - 信託報酬（0.1%）: 約36万円
     - クレカポイント還元: ▲180万円
     - 実質: ▲144万円（プラス！）

     差額: 576万円

     576万円は大きいですよね。

     もちろん、野村證券の担当者の方の
     アドバイスは価値があります。

     ですので、こういう使い分けはいかがでしょうか？

     - 複雑な商品や相談: 野村證券
     - シンプルな積立投資: SBI証券

     両方のメリットを活かせますし、
     コストも大幅に削減できます。

     いかがですか？」

顧客:「そういう使い方もできるんですね...」

営業:「はい。実際、そうされている方も多いんです。

     野村證券との付き合いも大切にしながら、
     コストを抑えられる部分はSBI証券で、
     という賢い使い方です。

     まずは新規の積立投資だけSBI証券で
     始めてみませんか？」
```

### シーン4: 「対面サポートがないと不安です」

```
顧客:「ネット証券って、対面サポートがないので
      不安なんです。」

営業:「お気持ちよくわかります。
     対面での安心感は大切ですよね。

     ただ、実際に対面証券の担当者と、
     年に何回お会いになりますか？」

顧客:「うーん、年に2-3回くらいかな...」

営業:「そうですよね。実は、多くの方が年2-3回なんです。

     その2-3回のために、
     年間数十万円の手数料を払い続けるのは
     もったいないと思いませんか？

     SBI証券でも、サポートはあります:
     - 電話サポート: 平日8:00-17:00
     - チャットサポート: 平日8:00-17:00
     - メールサポート: 24時間受付

     困った時はすぐに連絡できます。

     しかも、対面証券のように:
     - 予約する必要なし
     - 店舗に行く必要なし
     - 待ち時間なし

     電話一本で、即座に対応してもらえます。

     実際、多くのお客様が
     『電話で十分だった』とおっしゃいます。

     まずは試してみませんか？
     もし本当に不便だったら、対面証券に戻れば
     いいだけです。

     それだけで十分価値がありますよね。」

     SBI証券なら、対面証券と同じレベルの:
     - アナリストレポート
     - 市場動向レポート
     - 投資情報

     しかも24時間365日、いつでもアクセス可能です。

     対面証券だと、営業時間内に店舗に行くか、
     電話するしかないですよね。

     どちらが便利だと思いますか？」
```

## よくある異議と対応

### Q1: 「手数料安いのは分かったけど、何か裏があるのでは？」

**A**:
```
営業:「良い質問ですね。疑問に思われるのは当然です。

     裏はありません。理由は明確です:

     1. オンライン専業だから店舗コストがかからない
     2. 規模の経済（1,100万口座）で コスト削減
     3. システム投資で効率化

     つまり、対面証券にかかる:
     - 店舗の家賃
     - 大量の営業マンの人件費
     - 紙の資料作成費

     これらが不要なんです。

     そのコスト削減分を、お客様に還元しています。

     怪しいビジネスではなく、
     テクノロジーで効率化したビジネスモデルです。

     Amazonが安いのと同じ理屈ですね。」
```

**A**:
```

     ただ、その面倒さを乗り越える価値があるか
     計算してみましょう。

     移行にかかる時間: 約30分
     30年間の差額: 144万円

     時給換算すると:
     144万円 ÷ 0.5時間 = 288万円/時間

     30分の手間で144万円の差、
     つまり時給288万円の価値があります。

     これは、やる価値がありますよね？

     しかも、移行は一度だけ。
     その後は何もしなくても、
     毎年4.8万円多くポイントがもらえます。

     今日の30分で、未来が変わります。

     一緒に手続きしましょうか？」
```

## まとめ: 競合対策の基本姿勢

### 1. 他社を否定しない
- 「楽天証券も良い証券会社ですが...」
- 「野村證券も素晴らしい実績がありますよね...」

### 2. 数字で具体的に示す
- 「お得です」ではなく「144万円お得」
- 抽象論ではなく、具体的な差額

### 3. 顧客の状況に合わせる
- 一律の説明ではなく、顧客の投資額・期間で計算
- 「○○様の場合...」

### 4. 併用・段階的移行を提案
- 「全部移行してください」ではなく
- 「まず試してみて、気に入ったら移行」

### 5. 移行の手間を最小化
- 「手続きは30分で完了」
- 「一緒にやりましょう」とサポート提案
