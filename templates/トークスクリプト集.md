## 初回電話アプローチ

### シーン1: Webセミナー参加者へのフォロー

```
【オープニング】
営業:「○○様、お世話になっております。
     □□証券の●●と申します。
     先日は「新NISA完全ガイド」セミナーに
     ご参加いただき、誠にありがとうございました。」

顧客:「ああ、はい。」

営業:「お時間よろしいでしょうか?
     2-3分ほどお話しさせていただきたいのですが。」

【関係構築】
営業:「セミナーの内容はいかがでしたでしょうか?」

顧客:「わかりやすかったです。」

営業:「ありがとうございます。
     セミナーでは制度の概要をご説明しましたが、
     実際に○○様のご状況に合わせた
     具体的なプランをご提案させていただきたく
     ご連絡いたしました。」

【ニーズ確認】
営業:「差し支えなければお伺いしたいのですが、
     新NISAにご興味を持たれたきっかけは
     何かございますか?」

顧客:「老後の資金が心配で...」

営業:「そうですよね。多くの方が同じご不安を
     お持ちです。新NISAは老後資金準備に
     とても有効な制度です。

     ○○様のご年齢ですと、時間を味方につけた
     長期投資が可能ですので、大きなメリットが
     見込めます。」

【アポイント取得】
営業:「一度、詳しくお話しする時間を
     いただけないでしょうか?
     30分程度で、○○様に最適なプランを
     ご提案させていただきます。

     オンラインでも対面でも、どちらでも
     対応可能です。」

顧客:「そうですね...」

営業:「来週あたりで、ご都合のよろしい日は
     ございますでしょうか?
     平日の夕方や、土曜日も対応可能です。」

【クロージング】
顧客:「では、来週の水曜日の19時なら...」

営業:「ありがとうございます。
     それでは、○月○日（水）19時に
     オンラインでお話しさせていただきます。

     Zoom のリンクをメールでお送りいたしますので、
     そちらからご参加ください。

     事前に簡単なヒアリングシートも
     お送りしますので、可能な範囲で
     ご記入いただけますと幸いです。

     当日は、○○様のご状況に合わせた
     資産形成プランをご提案させていただきます。
     楽しみにしております。

     それでは、よろしくお願いいたします。」
```

### シーン2: 既存顧客（預金口座保有者）へのアプローチ

```
【オープニング】
営業:「○○様、いつもお世話になっております。
     □□証券の●●でございます。」

顧客:「ああ、どうも。」

営業:「お時間よろしいでしょうか?
     3分ほどお話しさせていただきたいのですが。」

【関係確認】
営業:「日頃は当社の定期預金をご利用いただき、
     ありがとうございます。

     本日は、○○様に是非お伝えしたい
     お得な情報がございまして、
     ご連絡させていただきました。」

【価値提供】
営業:「2024年から新しいNISA制度が始まったのは
     ご存知でしょうか?」

顧客:「ニュースで見ました。」

営業:「そうですよね。実は、この新NISA、
     従来のNISAから大幅に制度が拡充されまして、
     年間360万円まで非課税で投資できるように
     なりました。

     ○○様の資産状況を拝見しますと、
     預金が[XXX]万円ほどございますが、
     その一部を新NISAで運用することで、
     効率的な資産形成が可能になります。」

【具体例】
営業:「例えば、月3万円を30年間積み立てますと、
     年利5%で計算した場合、約2,500万円になります。
     通常ですと税金が約280万円かかりますが、
     新NISAなら税金ゼロです。

     ○○様のご年齢[XX]歳ですと、
     [XX]年間の運用が可能ですので、
     老後資金準備に最適です。」

【懸念解消】
顧客:「でも、投資って損することもあるんでしょう?」

営業:「おっしゃる通り、短期的には価格が変動します。
     ただし、20年以上の長期投資ですと、
     過去のデータでは元本割れしたケースは
     ほとんどございません。

     また、毎月少しずつ積み立てる方法ですと、
     価格変動のリスクを抑えることができます。」

【アポイント取得】
営業:「一度、詳しくご説明させていただきたいのですが、
     お時間をいただけないでしょうか?

     ○○様の資産状況を踏まえた、
     具体的なプランをご提案いたします。」

顧客:「そうですね。一度話を聞いてみようかな。」

営業:「ありがとうございます。
     それでは、来週あたりでご都合いかがでしょうか?
     当社支店にお越しいただくか、
     ○○様のご自宅にお伺いすることも可能です。」

【クロージング】
営業:「それでは、○月○日（金）14時に
     当社支店でお待ちしております。

     当日は、○○様専用の提案書をご用意して、
     詳しくご説明させていただきます。

     どうぞよろしくお願いいたします。」
```

## ヒアリング面談

### シーン3: 若年層（30代）へのヒアリング

```
【アイスブレイク】
営業:「本日はお時間いただきありがとうございます。
     オフィスからですか?テレワークですか?」

顧客:「今日はテレワークです。」

営業:「そうなんですね。最近はテレワークが増えて、
     働き方も変わってきましたよね。

     それでは早速ですが、本日は○○様の
     将来の目標やご要望をお伺いして、
     最適な資産形成プランをご提案させていただきます。」

【基本情報確認】
営業:「まず、基本的な情報を確認させてください。
     現在のお仕事は...」

【将来の目標】
営業:「○○様は、将来どのようなことを
     実現したいとお考えですか?

     例えば、住宅購入、お子様の教育、
     老後の生活など...」

顧客:「5年後くらいにマンションを買いたいと
      思っています。それと、老後も心配です。」

営業:「素晴らしいですね。
     5年後の住宅購入と、老後資金の準備、
     両方とも大切な目標ですね。

     住宅購入には頭金がどれくらい必要と
     お考えですか?」

顧客:「500万円くらいは準備したいです。」

営業:「わかりました。5年で500万円ですね。

     そして老後資金は、いくらくらい
     準備したいとお考えですか?」

顧客:「できれば2,000万円以上...」

営業:「2,000万円以上ですね。
     実現可能です。後ほど具体的なプランを
     ご提案いたします。」

【資産状況確認】
営業:「現在の資産状況について教えてください。
     差し支えない範囲で結構です。

     預貯金はどれくらいございますか?」

顧客:「200万円くらいです。」

営業:「ありがとうございます。
     月々の貯蓄は可能ですか?」

顧客:「月5万円くらいなら...」

営業:「素晴らしいですね。月5万円ですね。

     ボーナスは年何回ありますか?」

顧客:「年2回です。」

営業:「ボーナスからも貯蓄や投資に回せそうですか?」

顧客:「そうですね、年50万円くらいなら。」

【投資経験確認】
営業:「これまで投資のご経験はございますか?」

顧客:「ないです。全くの初心者です。」

営業:「大丈夫です。初めての方にも
     わかりやすくご説明いたします。

     投資について、どのようなイメージを
     お持ちですか?」

顧客:「正直、怖いイメージがあります。
      損したらどうしようかと...」

営業:「そうですよね。多くの方が同じように
     感じられます。

     ただ、投資には正しい方法があります。
     長期・積立・分散という3つの原則を
     守れば、リスクを大幅に抑えることができます。

     また、新NISAを使えば、税金もゼロになります。」

【リスク許容度確認】
営業:「もし、投資した資産が一時的に10%下がったら、
     どう感じますか?」

顧客:「うーん、不安にはなりますが、
      長期的に見て回復するなら大丈夫です。」

営業:「素晴らしい考え方です。
     短期的な変動を気にせず、長期的な視点を
     持つことが大切です。

     ○○様は、長期投資に向いていらっしゃいます。」

【ヒアリングまとめ】
営業:「それでは、ここまでお伺いした内容を
     まとめますね。

     ・5年後に住宅購入（頭金500万円）
     ・老後資金2,000万円以上
     ・現在の貯蓄200万円
     ・月5万円の積立可能
     ・年50万円のボーナス積立可能
     ・投資は初心者
     ・長期投資の考え方は理解

     以上でよろしいでしょうか?」

顧客:「はい、そうです。」

営業:「ありがとうございます。
     それでは、○○様に最適なプランを
     ご提案させていただきます。

     次回、具体的な提案書をご用意して、
     詳しくご説明いたします。

     1週間後くらいに、再度お時間いただけますか?」
```

## 提案プレゼンテーション

### シーン4: 提案書を使ったプレゼンテーション

```
【オープニング】
営業:「本日はお時間いただきありがとうございます。
     前回のヒアリング内容を基に、
     ○○様専用の資産形成プランをご用意いたしました。

     お手元の提案書をご覧ください。」

【エグゼクティブサマリー】
営業:「まず、1ページ目のサマリーをご覧ください。

     ○○様の目標は、5年後の住宅購入資金500万円と、
     老後資金2,000万円でしたね。

     本日ご提案するプランでは、
     月5万円の積立と年50万円のボーナス積立で、
     両方の目標を達成できる内容となっております。」

【現状分析】
営業:「3ページをご覧ください。
     ○○様の現状をまとめております。

     現在30歳、貯蓄200万円、
     月5万円の積立が可能という状況ですね。

     30歳からスタートできることは、
     時間という最大の武器を持っていることになります。」

【新NISA説明】
営業:「5ページをご覧ください。
     新NISA制度についてご説明します。

     [グラフを指差して]
     通常、投資で100万円の利益が出ると、
     約20万円の税金がかかります。

     しかし、新NISAなら税金ゼロです。
     30年間で考えると、数百万円の差になります。」

【具体的提案】
営業:「それでは、7ページの具体的なプランを
     ご覧ください。

     ○○様には、2段階のプランをご提案します。

     【フェーズ1: 住宅購入資金準備（5年間）】
     月5万円の積立のうち、
     ・3万円を新NISA（つみたて投資枠）
     ・2万円を預金

     ボーナス年50万円のうち、
     ・30万円を新NISA（成長投資枠）
     ・20万円を預金

     5年後、新NISA分が約450万円、
     預金が約220万円で、合計約670万円になります。

     住宅購入時に、預金220万円+新NISA の一部を
     頭金に使います。

     【フェーズ2: 老後資金準備（25年間）】
     住宅購入後、引き続き新NISAで積立を継続。
     月8万円（住宅ローンの調整で増額）

     65歳時点で約3,000万円の資産を目指します。」

【シミュレーション】
営業:「10ページのシミュレーションをご覧ください。

     [グラフを指差して]
     年利5%で計算しますと、このような推移になります。

     青い線が積立額、赤い線が運用後の資産です。
     複利効果で、時間とともに差が開いていくのが
     わかりますね。」

【リスク説明】
営業:「12ページをご覧ください。
     リスクについてもしっかりご説明します。

     投資信託は元本保証ではありませんので、
     一時的に価格が下がることもあります。

     [グラフを指差して]
     ただし、このグラフのように、
     長期的には上昇トレンドです。

     また、毎月積立することで、
     価格が安い時に多く買えるという
     メリットもあります。」

【質疑応答】
営業:「ここまでで、ご不明な点はございますか?」

顧客:「うーん、5%って本当に達成できるんですか?」

営業:「良いご質問ですね。
     5%は過去30年間の世界株式の平均リターンです。

     もちろん、毎年5%ではなく、
     良い年は+20%、悪い年は-10%など
     変動します。

     ただ、長期的に見ると、平均して5-7%の
     リターンが期待できるというデータがあります。

     15ページに、年利3%、5%、7%の
     シナリオ分析もございますので、
     ご覧ください。」

【クロージング導入】
営業:「いかがでしょうか。
     ○○様の目標達成に向けて、
     現実的なプランだと思いませんか?」

顧客:「そうですね。具体的でわかりやすかったです。」

営業:「ありがとうございます。
     それでは、次のステップに進みませんか?」
```

## 異議対応

### シーン5: 「検討させてください」への対応

```
顧客:「提案はわかりました。
      一度、検討させてください。」

営業:「ありがとうございます。
     もちろん、じっくりご検討いただきたいと思います。

     差し支えなければ、特にどのあたりを
     検討されたいですか?」

顧客:「全体的に...」

営業:「そうですか。では、このようにお考えいただくと
     いかがでしょうか?

     ・投資の必要性: 納得できましたか?
     ・新NISAの仕組み: 理解できましたか?
     ・提案内容: 自分に合っていると思いますか?
     ・リスク: 許容できる範囲ですか?
     ・投資額: 無理のない金額ですか?

     この中で、気になる点はございますか?」

顧客:「リスクがやっぱり気になります。」

営業:「なるほど、リスクですね。
     具体的にどのようなリスクが気になりますか?」

顧客:「元本割れしたら嫌だなと...」

営業:「おっしゃる通りですね。
     元本割れのリスクはございます。

     ただ、このグラフをもう一度ご覧ください。
     [リスク説明資料を見せる]

     ・短期的(1-3年): 元本割れリスクあり
     ・中期的(5-10年): リスク低減
     ・長期的(15年以上): ほぼリスクなし

     ○○様の場合、30年という長期投資ですので、
     元本割れのリスクは極めて低いです。

     また、最初は少額から始めて、
     慣れてきたら増額する方法もあります。

     例えば、最初の3ヶ月は月1万円で試してみて、
     大丈夫そうなら月3万円、月5万円と
     増やしていくのはいかがでしょうか?」

顧客:「それなら、ちょっと安心ですね。」

営業:「そうですよね。無理なく始めることが大切です。

     それでは、まずは月1万円から
     スタートしてみませんか?

     実際に投資を始めてみると、
     イメージと違うことがわかると思います。

     3ヶ月後に、改めてご状況を確認して、
     増額するかどうか一緒に考えましょう。」

顧客:「わかりました。それならやってみます。」
```

### シーン6: 「今は余裕がない」への対応

```
顧客:「興味はあるんですが、今は余裕がなくて...」

営業:「そうですか。確かに、無理のない範囲で
     始めることが大切ですね。

     差し支えなければ、月々どれくらいなら
     可能でしょうか?」

顧客:「うーん、1万円も厳しいかな...」

営業:「わかりました。
     実は、当社では月100円から始められるんです。」

顧客:「100円?」

営業:「はい、100円です。
     もちろん、100円では大きく増えませんが、
     投資を始めるきっかけにはなります。

     まずは月1,000円や3,000円から始めて、
     ボーナス時に少し多めに投資する方法も
     ございます。

     例えば、
     ・通常月: 月3,000円
     ・ボーナス月: 10万円

     年間で約24万円の投資になります。

     10年続けると、約310万円(年利5%)になります。

     これでも、かなりの資産形成ができますよ。」

顧客:「それくらいならできそうです。」

営業:「素晴らしいです。
     大切なのは、始めることと続けることです。

     金額はいつでも変更できますので、
     まずは無理のない範囲でスタートしましょう。

     収入が増えたり、支出が減ったりしたら、
     その時に増額を検討すればいいんです。」

顧客:「わかりました。じゃあ、やってみます。」

営業:「ありがとうございます。
     まずは月3,000円から始めましょう。

     3ヶ月後に状況を確認して、
     増額できそうかどうか相談しましょう。」
```

### シーン7: 「家族と相談したい」への対応

```
顧客:「妻と相談してから決めたいです。」

営業:「もちろんです。ご家族で相談されるのは
     とても大切ですね。

     奥様もご一緒に、もう一度ご説明させて
     いただくことも可能ですよ。」

顧客:「そうですね。妻も一緒に聞いた方がいいかも。」

営業:「ぜひそうしましょう。
     今週末や来週あたりで、奥様のご都合は
     いかがでしょうか?

     ご自宅にお伺いすることもできますし、
     オンラインでも対応可能です。」

顧客:「土曜日の午後なら、妻も家にいます。」

営業:「ありがとうございます。
     それでは、今週土曜日の14時に
     オンラインでご説明させていただきます。

     奥様にも事前に資料をお送りしますので、
     メールアドレスを教えていただけますか?」

【奥様同席の面談当日】

営業:「本日は奥様もご一緒にありがとうございます。
     ご主人様から事前にお話は聞かれていますか?」

奥様:「少し聞きました。投資を始めたいって。」

営業:「そうですか。それでは改めて、
     最初から丁寧にご説明させていただきます。

     [提案内容を説明]

     いかがでしょうか。ご不明な点や
     ご心配な点はございますか?」

奥様:「損したらどうするんですか?」

営業:「大切なご質問ですね。
     正直に申し上げますと、短期的には
     損失が出る可能性もございます。

     ただし、
     ・長期投資(15年以上)
     ・積立投資
     ・分散投資
```

## まとめ

これらのトークスクリプトは参考例です。実際の面談では、顧客の反応や状況に応じて柔軟に対応してください。

**重要なポイント**:
1. 顧客の話をよく聞く
2. 共感を示す
3. わかりやすい言葉で説明
4. 無理に売り込まない
5. 長期的な関係を重視
6. 誠実な対応

**禁止事項**:
- 断定的な表現
- リスクの過小評価
- 過度なプレッシャー
- 虚偽の説明
