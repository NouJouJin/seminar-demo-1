## 資料の保管・管理

### 保管場所
- 社内サーバー: 共有フォルダ構成
  ```
  /営業資料/
    /顧客向け資料/
      /セグメント別/
      /営業プロセス別/
    /社内用資料/
    /テンプレート/
    /過去資料アーカイブ/
  ```

### 管理ルール
- バージョン管理の徹底
- 更新履歴の記録
- アクセス権限の設定
- 定期的な見直し
- 不要資料の廃棄

### 担当者
- 資料管理責任者: 営業企画部長
- 更新担当者: 各資料カテゴリ別に指定
- 承認者: 管理職

## チェックリストの使い方

1. **営業プロセスごとに確認**
   - 各ステップで必要な資料が揃っているか確認
   - 不足資料は優先的に作成

2. **顧客セグメントごとに確認**
   - 担当セグメントの専用資料を準備
   - カスタマイズの検討

3. **定期的な見直し**
   - 月次: 使用頻度の確認
   - 四半期: 内容の更新必要性確認
   - 年次: 全体的な見直し

4. **改善提案**
   - 使いにくい資料の改善
   - 新規資料の提案
   - 不要資料の削除提案

## まとめ

この必要資料チェックリストを活用することで、新NISA投資信託販売における営業活動を網羅的にサポートできます。

**重要ポイント**
1. 営業プロセスに沿った資料準備
2. 顧客セグメントに応じたカスタマイズ
3. 定期的な資料の見直しと更新
4. 法令遵守の徹底
5. 効率的な資料管理

各資料のテンプレートは templates/ フォルダに格納されています。
