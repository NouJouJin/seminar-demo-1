## 各ステップ詳細

### ステップ1: 見込み客発掘（リードジェネレーション）

#### 目的
新NISA投資信託に関心のある潜在顧客を特定し、リストアップする

#### 主要活動

**1-1. マーケティング活動**
- Webセミナー開催（月2-4回）
  - テーマ例: 「新NISA完全ガイド」「20代からの資産形成」「退職金活用術」
- オフラインセミナー開催（月1-2回）
  - 会場: 支店、ホテル、公共施設
- SNS・Web広告
  - Facebook、Instagram、Google広告
  - ターゲティング: 年齢、職業、興味関心
- コンテンツマーケティング
  - ブログ記事、YouTube動画
  - メールマガジン配信

**1-2. 既存顧客からの発掘**
- 預金口座保有者への案内
- 旧NISA利用者への移行案内
- 他商品利用者へのクロスセル
- 顧客紹介プログラム

**1-3. 紹介・口コミ**
- 既存顧客からの紹介
- 専門家（税理士、FP等）からの紹介
- 法人経営者からの従業員紹介

**1-4. アウトバウンド活動**
- テレマーケティング
- ダイレクトメール
- 訪問営業（富裕層向け）

#### 必要ツール・資料
- セミナー企画書・案内状
- Web広告クリエイティブ
- ランディングページ
- 資料請求フォーム
- 顧客データベース
- CRMシステム

#### KPI
| 指標 | 目標値 |
|------|--------|
| 月間リード獲得数 | 1,000件 |
| Webセミナー参加者数 | 200名/回 |
| オフラインセミナー参加者数 | 30名/回 |
| 資料請求数 | 150件/月 |
| 紹介件数 | 50件/月 |
| CPL(顧客獲得単価) | 5,000円以下 |

#### 成功のポイント
- ターゲットセグメントに合ったメッセージング
- 複数チャネルの組み合わせ
- タイムリーなフォローアップ
- 魅力的なコンテンツ提供

### ステップ2: 初回接触（ファーストコンタクト）

#### 目的
リードとの信頼関係を構築し、次のステップ（ヒアリング）につなげる

#### 主要活動

**2-1. 接触方法の選択**
- 電話: 迅速な接触、反応確認
- メール: 詳細情報提供、時間の自由度
- 訪問: 高額顧客、信頼構築
- オンライン面談: 効率性、利便性

**2-2. 初回接触の内容**
- 自己紹介と会社紹介
- セミナー参加/資料請求への御礼
- 簡単なヒアリング（興味関心の確認）
- 次回面談のアポイント取得
- 有益な情報提供（押し売りしない）

**2-3. タイミング**
- セミナー参加後: 24時間以内
- 資料請求後: 48時間以内
- 紹介: 1週間以内
- DM送付後: 3-5営業日後

#### 電話スクリプト例
```
【オープニング】
「○○様、お世話になっております。
□□証券の●●と申します。
先日は新NISAセミナーにご参加いただき、
ありがとうございました。」

【目的説明】
「セミナーの内容についてご不明な点はございませんでしたか?
また、○○様のご状況に合わせた運用方法について
詳しくご説明させていただきたいと思っております。」

【アポイント取得】
「つきましては、一度ゆっくりとお話しする時間を
いただきたいのですが、来週あたりでご都合いかがでしょうか。
30分程度で結構です。オンラインでも対面でも可能です。」

【クロージング】
「ありがとうございます。それでは○月○日○時に
お伺い(オンライン接続)させていただきます。
当日はどうぞよろしくお願いいたします。」
```

#### 必要ツール・資料
- 顧客情報シート
- 電話スクリプト
- メールテンプレート
- 会社案内
- 担当者プロフィール
- アポイント管理システム

#### KPI
| 指標 | 目標値 |
|------|--------|
| リードへの接触率 | 80%以上 |
| アポイント取得率 | 30%以上 |
| 平均接触所要時間 | 10分以内 |
| 24時間以内接触率 | 60%以上 |

#### 成功のポイント
- 迅速な対応
- 押し売りしない姿勢
- 顧客メリットの明確化
- 柔軟な日程調整
- 適切なチャネル選択

### ステップ3: ヒアリング（ニーズ把握）

#### 目的
顧客の詳細な状況、ニーズ、目標を把握し、最適な提案の基礎を作る

#### 主要活動

**3-1. 事前準備**
- 顧客情報の確認
- ヒアリングシートの準備
- 必要資料の準備
- 質問項目のリストアップ

**3-2. ヒアリング実施**

**財務状況の把握**
- 年収・収入源
- 金融資産の状況（預金、株式、保険等）
- 負債の状況
- 月々の貯蓄額
- 保有不動産

**ライフプラン・目標**
- 家族構成
- 将来のライフイベント（結婚、住宅購入、教育等）
- 退職予定時期
- 老後のイメージ
- 相続に関する考え

**投資経験・知識**
- 過去の投資経験
- 現在の保有商品
- 投資に関する知識レベル
- 情報収集の方法
- 過去の成功・失敗体験

**リスク許容度**
- 元本割れに対する考え
- 価格変動への耐性
- 投資期間
- 流動性ニーズ
- 心理的リスク許容度

**ニーズ・関心事**
- 投資の目的（資産形成、収入確保、相続対策等）
- 新NISAへの関心度
- 税務対策への関心
- その他の金融ニーズ

**3-3. リスク許容度診断**
- 診断ツールの実施
- 結果の説明
- 適合性の確認

**3-4. ヒアリング内容のまとめ**
- 重要ポイントの整理
- 顧客ニーズの明確化
- 提案の方向性確認

#### ヒアリングの質問例

**オープンクエスチョン**
- 「将来の目標について教えてください」
- 「投資について、どのようにお考えですか?」
- 「新NISAについて、どのようなイメージをお持ちですか?」

**クローズドクエスチョン**
- 「現在、投資信託は保有されていますか?」
- 「月々の貯蓄は可能ですか?」
- 「価格が一時的に10%下がっても、長期保有できますか?」

**確認質問**
- 「つまり、○○ということでよろしいでしょうか?」
- 「最も重視されているのは△△ということですね?」

#### 必要ツール・資料
- ヒアリングシート（セグメント別）
- ライフプラン表
- リスク許容度診断ツール
- 資産状況整理シート
- 家計収支表
- 新NISA制度説明資料
- メモ・記録ツール

#### KPI
| 指標 | 目標値 |
|------|--------|
| ヒアリング完了率 | 80%以上 |
| 平均ヒアリング時間 | 60分 |
| リスク許容度診断実施率 | 100% |
| 次回提案アポ取得率 | 90%以上 |

#### 成功のポイント
- 傾聴の姿勢
- 適切な質問
- 安心感の提供
- プライバシーへの配慮
- 専門性のアピール
- 顧客本位の姿勢

### ステップ4: 提案（プレゼンテーション)

#### 目的
ヒアリング内容を基に、顧客に最適な新NISA活用プランを提案する

#### 主要活動

**4-1. 提案書作成**
- ヒアリング内容の分析
- 最適商品の選定
- ポートフォリオ設計
- シミュレーション作成
- 提案書の作成（セグメント別テンプレート活用）

**4-2. 提案内容の構成**

**イントロダクション（5分）**
- ヒアリング内容の確認
- 提案の全体像説明

**現状分析（10分）**
- 現在の資産状況まとめ
- 課題の明確化
- 目標の再確認

**新NISA制度説明（10分）**
- 制度のメリット
- 非課税効果の試算
- 旧制度との比較

**具体的提案（20分）**
- 推奨ポートフォリオ
- 商品詳細説明
- 投資金額・期間
- 期待リターンとリスク
- シミュレーション提示

**実行プラン（10分）**
- スタート時期
- 手続きの流れ
- 必要書類
- サポート体制

**質疑応答（15分）**
- 疑問点の解消
- 不安への対応
- 代替案の提示

**4-3. 提案のポイント**

**顧客本位**
- 顧客のニーズに合った提案
- 無理のない投資額
- 適切なリスクレベル

**わかりやすさ**
- 専門用語の避ける
- 図解・グラフの活用
- 具体的な数字で説明

**透明性**
- 手数料の明示
- リスクの明確な説明
- メリット・デメリット両方説明

**実現可能性**
- 現実的なプラン
- 段階的な実行
- 柔軟な調整可能性

#### 提案書の構成例

```
【提案書目次】

1. 表紙（顧客名、提案日、担当者）

2. エグゼクティブサマリー
   - 提案の概要（1ページ）

3. ヒアリング内容まとめ
   - お客様の状況・目標

4. 現状分析
   - 資産状況
   - 課題の整理

5. 新NISA制度について
   - 制度の概要
   - メリット
   - 非課税効果試算

6. 提案内容
   - 推奨ポートフォリオ
   - 商品詳細
   - 投資金額・期間

7. シミュレーション
   - 将来予測
   - リスク分析
   - シナリオ比較

8. 実行プラン
   - スケジュール
   - 手続きの流れ

9. サポート体制
   - アフターフォロー
   - レポーティング

10. 付録
    - 商品説明書
    - リスク説明
    - 用語集
```

#### 必要ツール・資料
- 提案書テンプレート（セグメント別）
- 商品パンフレット
- シミュレーションツール
- リスク説明資料
- 手数料一覧
- 実績データ
- プレゼンテーション資料

#### KPI
| 指標 | 目標値 |
|------|--------|
| 提案実施率 | 90%以上 |
| 平均提案時間 | 70分 |
| 提案書作成期間 | 3-5営業日 |
| 顧客満足度 | 4.0以上/5.0 |

#### 成功のポイント
- 十分な準備
- カスタマイズされた提案
- わかりやすい説明
- 双方向のコミュニケーション
- 誠実な対応
- 専門性の発揮

### ステップ5: クロージング（成約判断）

#### 目的
顧客の意思決定をサポートし、契約締結につなげる

#### 主要活動

**5-1. 意思確認**
- 提案内容の理解度確認
- 疑問点・不安点のヒアリング
- 意思決定の状況確認

**5-2. 異議対応（オブジェクションハンドリング）**

**よくある異議と対応**

| 異議 | 対応方法 |
|------|----------|
| 「検討させてください」 | 具体的な検討ポイントを確認、期限設定、追加情報提供 |
| 「今は余裕がない」 | 少額スタート提案、段階的増額プラン、優先順位の整理 |
| 「損するのが怖い」 | リスク説明の徹底、少額・分散投資、長期投資のメリット説明 |
| 「他と比較したい」 | 比較ポイント提示、当社の強み説明、再面談設定 |
| 「家族と相談」 | 家族同席面談の提案、家族向け資料提供、期限設定 |
| 「タイミングが」 | 早期開始のメリット説明、柔軟なスタート時期、市場タイミングの説明 |

**5-3. クロージングテクニック**

**試用クロージング**
「ここまでの内容で、ご不明な点はございませんか?」

**仮定クロージング**
「もし始められるとしたら、月々いくらくらいからがよろしいですか?」

**選択クロージング**
「月3万円からと月5万円から、どちらがご希望に合いますか?」

**段階的クロージング**
「まずは少額からスタートして、慣れてきたら増額する方法もあります」

**緊急性クロージング**
「新NISA は早く始めるほど、非課税メリットが大きくなります」

**5-4. 最終確認**
- 契約内容の最終確認
- リスク説明の再確認
- 重要事項説明
- 質疑応答

**5-5. 次ステップの説明**
- 契約手続きの流れ
- 必要書類
- スケジュール
- サポート体制

#### クロージングのタイミング

**積極的サイン（バイイングシグナル）**
- 「具体的にはいつから始められますか?」
- 「手続きは簡単ですか?」
- 「他の人はどれくらい投資していますか?」
- 前のめりな姿勢、メモを取る

**消極的サイン**
- 時計を見る、視線が合わない
- 後ろ向きな質問が多い
- 「検討します」を繰り返す

#### 必要ツール・資料
- 異議対応スクリプト
- 比較資料
- 契約書類一式
- 重要事項説明書
- リスク説明書
- FAQ集
- 顧客事例集

#### KPI
| 指標 | 目標値 |
|------|--------|
| 成約率 | 40%以上 |
| 平均クロージング期間 | 2週間以内 |
| 異議解決率 | 60%以上 |
| 再提案機会創出率 | 80%以上 |

#### 成功のポイント
- 焦らない姿勢
- 顧客の意思決定を尊重
- 丁寧な異議対応
- 柔軟な代替案提示
- 適切なクロージングタイミング
- フォローアップの約束

**6-1. 契約前の最終確認**
- 契約内容の再確認
- 顧客情報の確認
- 適合性の最終チェック

**6-2. 書類説明・署名**
- 契約書類の説明
- 重要事項の再確認
- 署名・捺印
- 本人確認

**6-3. 必要書類の受領**
- 本人確認書類
- マイナンバー確認書類
- 印鑑
- その他必要書類

**6-4. 手続き実行**
- 口座開設手続き
- 商品申込手続き
- 入金確認
- システム登録

**6-5. 書類交付**
- 契約書控え
- 目論見書
- 運用報告書の説明
- 今後のスケジュール説明

**6-6. 初回フォローの予定**
- 次回連絡日の設定
- 連絡方法の確認
- 緊急時の連絡先案内

#### 契約時の必須事項

- クーリングオフの説明

**顧客保護**
- リスクの再確認
- 手数料の明示
- 解約条件の説明
- 苦情・相談窓口の案内

#### 必要ツール・資料

- 本人確認書類リスト
- 手続きチェックリスト
- 書類交付リスト
- システム登録マニュアル
- 顧客控え書類

#### KPI
| 指標 | 目標値 |
|------|--------|
| 契約完了率 | 95%以上 |
| 平均手続き所要時間 | 30分以内 |
| 書類不備率 | 5%以下 |
| 契約キャンセル率 | 2%以下 |

#### 成功のポイント
- 丁寧な説明
- 書類の事前準備
- スムーズな手続き
- 不明点の即座解消
- 安心感の提供

### ステップ7: フォローアップ（継続サポート）

#### 目的
顧客との長期的な関係を構築し、満足度を高め、追加ビジネスにつなげる

#### 主要活動

**7-1. 短期フォロー（契約後1-3ヶ月）**

**1週間後**
- 電話またはメールで状況確認
- 口座開設完了確認
- 運用開始確認
- 不明点のヒアリング

**1ヶ月後**
- 初回運用レポート提供
- 市場動向の説明
- 運用状況の説明
- 質疑応答
- 不安の解消

**3ヶ月後**
- 詳細レビュー面談
- ポートフォリオ確認
- 市場環境の説明
- 継続の重要性説明
- 増額提案（可能な場合）

**7-2. 中長期フォロー（3ヶ月以降）**

**定期報告**
- 月次レポート（メール）
- 四半期レポート（郵送）
- 半期レポート（対面）
- 年次総合レポート（対面）

**定期面談**
- 半期に1回: 運用状況レビュー
- 年1回: 総合レビュー、次年度プラン
- 臨時: 市場急変時、ライフイベント時

**情報提供**
- 市場動向レポート
- 新商品情報
- 税制改正情報
- セミナー案内

## 失注分析と改善策

### 主要失注理由と対策

#### 1. 「検討します」（失注理由の30%）

**原因分析**
- 意思決定の先延ばし
- 不安・疑問の未解消
- 比較検討したい
- 家族の反対

**改善策**
- 具体的な検討ポイントを確認
- 期限付きフォローアップ設定
- 追加情報の提供
- 家族同席面談の提案
- トライアル提案（少額スタート）

#### 2. 「今は余裕がない」（失注理由の25%）

**原因分析**
- 資金余力の不足
- 優先順位の低さ
- メリットの理解不足

**改善策**
- 少額スタートプランの提示
- 優先順位の再整理支援
- 長期メリットの再説明
- タイミングを変えた再提案

#### 3. 「リスクが怖い」（失注理由の20%）

**原因分析**
- リスク理解不足
- 過去の失敗体験
- 元本保証志向

**改善策**
- リスク説明の徹底
- 分散投資の説明強化
- 少額・長期投資の提案
- 保守的商品の提案
- 成功事例の紹介

#### 4. 「他社と比較したい」（失注理由の15%）

**原因分析**
- 情報不足
- 信頼関係不足
- より良い条件を求める

**改善策**
- 当社の強みの明確化
- 比較表の提供
- 手数料等の透明性確保
- 付加価値サービスの説明
- 期限付きフォロー

#### 5. 「タイミングではない」（失注理由の10%）

**原因分析**
- ライフイベントの変化
- 市場環境への不安
- 時期的な問題

**改善策**
- 適切なタイミングの提案
- 市場タイミングの説明
- 長期視点の重要性説明
- リマインド設定
