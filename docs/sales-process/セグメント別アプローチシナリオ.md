## A. 若年資産形成層（20-30代）

### シナリオ1: デジタルマーケティング経由の新規顧客

#### フェーズ1: 初回接触（1週目）
**アプローチ方法**:
- Webセミナー「20代から始める新NISA完全ガイド」への参加を確認
- セミナー終了後24時間以内にフォローメール送付
- オンライン個別相談の案内（30分無料）

**使用ツール・資料**:
- フォローメールテンプレート（若年層向け）
- 新NISA基礎ガイドPDF
- オンライン面談予約リンク

**トークポイント**:
```
「セミナーにご参加いただきありがとうございました。
20代から資産形成を始めることで、時間を味方につけた
複利効果を最大限に活用できます。

月々1万円からでも、30年後には大きな差が生まれます。
まずは気軽にご相談ください。」
```

#### フェーズ2: ヒアリング・ニーズ把握（2週目）
**アプローチ方法**:
- Zoomでのオンライン面談（30分）
- ライフプランヒアリングシート記入
- 投資目的・目標の明確化

**ヒアリング項目**:
1. 現在の資産状況（貯蓄額、月々の貯蓄額）
2. 将来の目標（結婚、住宅購入、子供の教育等）
3. リスク許容度の確認
4. 投資に対する不安や懸念
5. 情報収集の習慣（SNS、Web等）

**使用ツール・資料**:
- ライフプランヒアリングシート
- リスク許容度診断ツール
- 20代向け資産形成シミュレーション

**トークポイント**:
```
「まずは○○様の将来の目標を教えてください。
例えば5年後に住宅購入を考えている場合と、
30年後の老後資金を準備する場合では、
最適な投資方法が変わってきます。」
```

#### フェーズ3: 提案（3週目）
**アプローチ方法**:
- カスタマイズした投資プラン提示
- 具体的なシミュレーション提示
- スタート金額の柔軟な設定

**提案内容例**:
```
【新NISA活用プラン - 30代会社員Aさんの場合】

つみたて投資枠: 月3万円
- eMAXIS Slim 全世界株式: 月2万円
- eMAXIS Slim バランス(8資産均等型): 月1万円

成長投資枠: ボーナス時 年50万円
- ひふみプラス: 25万円
- グローバルAIファンド: 25万円

30年後の想定資産: 約2,800万円
（年利5%で試算）
```

**使用ツール・資料**:
- カスタマイズ提案書
- 商品説明資料（わかりやすい図解）
- 長期投資シミュレーション
- スマホアプリデモ画面

**トークポイント**:
```
「まずは月3万円から始めましょう。
アプリで毎日残高をチェックでき、
慣れてきたら増額も可能です。

最初の3ヶ月は市場の変動に慣れる期間と考え、
その後、状況を見ながら調整していきましょう。」
```

#### フェーズ4: クロージング（4週目）
**アプローチ方法**:
- 不安点の最終確認
- 少額スタートの提案（心理的ハードル低減）
- 手続きの簡便さアピール
- アフターフォロー体制の説明

**クロージングトーク**:
```
「新NISA は2024年から始まっており、
早く始めるほど非課税メリットが大きくなります。

まずは月1万円からでもスタートして、
慣れてきたら増額する方も多いですよ。

口座開設はスマホで10分、
最短3営業日で投資を始められます。」
```

**使用ツール・資料**:
- 口座開設ガイド（スマホ版）
- 申込書類一式
- よくある質問FAQ
- フォロー体制説明資料

#### フェーズ5: フォローアップ（契約後）
**1ヶ月後**:
- 運用状況の確認メール
- 市場動向の簡易レポート送付
- 不明点のヒアリング

**3ヶ月後**:
- オンライン面談で運用状況レビュー
- 増額の提案（可能な場合）
- 紹介依頼

**6ヶ月後**:
- ポートフォリオ見直し提案
- 新商品情報の提供
- 顧客満足度調査

## B. 中堅資産蓄積層（40-50代）

### シナリオ2: 既存顧客（預金口座保有者）へのアプローチ

#### フェーズ1: 初回接触（1週目）
**アプローチ方法**:
- ダイレクトメール送付「新NISA特別ご案内」
- 3営業日後に電話フォロー
- 専門家による個別相談会への招待

**使用ツール・資料**:
- DMレター（高級感のあるデザイン）
- 新NISA制度変更点まとめ
- 個別相談会案内状

**電話トークスクリプト**:
```
「○○様、いつもお世話になっております。
先日、新NISAに関するご案内をお送りしましたが、
ご覧いただけましたでしょうか。

2024年から制度が大幅に拡充され、
年間360万円まで非課税で投資できるように
なりました。

○○様の資産状況を拝見しますと、
この制度を活用することで、
老後資金準備を効率的に進められる可能性がございます。

一度、詳しくご説明させていただきたいのですが、
来週あたりでご都合いかがでしょうか。」
```

#### フェーズ2: ヒアリング・ニーズ把握（2週目）
**アプローチ方法**:
- 支店または訪問での対面面談（60分）
- 詳細な資産状況の把握
- ライフプラン・退職後プランのヒアリング

**ヒアリング項目**:
1. 総資産状況（預金、株式、保険、不動産等）
2. 子供の教育費負担状況・計画
3. 退職金の見込み額・受取時期
4. 老後生活のイメージ・必要資金
5. 相続に関する考え
6. 現在の投資経験・保有商品
7. リスク許容度（詳細分析）

**使用ツール・資料**:
- 資産状況ヒアリングシート
- ライフプラン表（詳細版）
- 退職後資金シミュレーター
- リスク許容度診断（詳細版）
- 相続対策チェックリスト

**トークポイント**:
```
「○○様の場合、お子様が大学を卒業される
3年後からは教育費負担が軽減されますね。

そのタイミングで投資額を増やすことも
視野に入れながら、まずは現在可能な範囲で
新NISAを活用していきましょう。

また、退職金を受け取られる10年後を見据えた
長期的なプランも合わせて考えていきます。」
```

#### フェーズ3: 提案（3-4週目）
**アプローチ方法**:
- 総合的な資産運用プラン提示
- 複数シナリオの提案（保守・中庸・積極）
- 税務メリットの具体的試算
- 退職金運用プランの提示

**提案内容例**:
```
【新NISA活用プラン - 50代会社員Bさんの場合】

現状分析:
- 総金融資産: 2,000万円（預金1,500万円、株式500万円）
- 年収: 800万円
- 子供: 大学2年生（あと2年で卒業）
- 退職予定: 10年後（退職金見込2,000万円）

提案: 中庸シナリオ

つみたて投資枠: 月10万円（上限）
- 世界経済インデックスファンド: 月5万円
- バランス型ファンド(株式50%): 月5万円

成長投資枠: 年120万円
- グローバル高配当株ファンド: 60万円
- 先進国株式ファンド: 30万円
- 新興国株式ファンド: 30万円

10年後の想定資産:
- 新NISA資産: 約2,500万円（年利4%で試算)
- 既存資産: 約2,200万円
- 退職金: 2,000万円
- 合計: 約6,700万円

65歳からの取り崩しシミュレーション:
月20万円を30年間受け取り可能
```

**使用ツール・資料**:
- オーダーメイド提案書（製本版）
- 詳細シミュレーション資料
- 商品パンフレット（厳選3-5本）
- 税務メリット試算書
- 比較表（保守・中庸・積極）

**トークポイント**:
```
「○○様の場合、お子様が卒業される2年後には
教育費が年間200万円ほど軽減されます。

その分を新NISAに充てることで、
10年後の退職時には新NISAだけで
2,500万円程度の資産形成が見込めます。

また、退職金2,000万円の運用方法も
合わせてご提案させていただいています。」
```

#### フェーズ4: クロージング（5-6週目）
**アプローチ方法**:
- 配偶者同席での最終説明（可能な場合）
- 疑問点・懸念事項の徹底的な解消
- 段階的スタートの提案
- 専門家（税理士等）紹介の提案

**クロージングトーク**:
```
「それでは、まずは月5万円からスタートして、
お子様が卒業されるタイミングで月10万円に
増額するプランでいかがでしょうか。

市場環境を見ながら柔軟に調整できますので、
ご安心ください。

また、3ヶ月ごとに運用状況をご報告し、
年に一度は詳細なレビュー面談を
させていただきます。」
```

**使用ツール・資料**:
- 契約書類一式
- 商品説明書（詳細版）
- アフターフォロースケジュール
- 担当者連絡先カード
- 緊急時対応マニュアル

#### フェーズ5: フォローアップ（契約後）
**1ヶ月後**:
- 電話での状況確認
- 運用レポート郵送

**3ヶ月後**:
- 対面での運用状況レビュー
- 市場動向説明
- 質疑応答

**6ヶ月後**:
- 詳細レビュー面談
- ポートフォリオ調整提案
- 税務相談（必要に応じて）

**1年後**:
- 年次レビュー面談
- 次年度プラン提案
- 相続対策の提案
- 紹介依頼

## C. シニア資産活用層（60代以上）

### シナリオ3: 退職金受領者へのアプローチ

#### フェーズ1: 初回接触（1週目）
**アプローチ方法**:
- 退職者向けセミナー「退職金活用と新NISA」開催
- 個別相談会の案内（セミナー参加者限定）
- 丁寧な電話フォロー

**使用ツール・資料**:
- セミナー案内状（大きめの文字）
- 退職金活用ガイドブック
- 新NISA安心ガイド（シニア向け）

**電話トークスクリプト**:
```
「○○様、この度はご退職おめでとうございます。
長年のお勤め、お疲れ様でございました。

退職金の運用について、多くの方がお悩みになられます。
特に、低金利の現在、預金だけでは
インフレに負けてしまう可能性もございます。

来週、退職金活用に関する少人数セミナーを
開催いたします。専門家がわかりやすく
ご説明いたしますので、ぜひご参加ください。

お一人様でも、ご夫婦でのご参加も歓迎です。」
```

#### フェーズ2: ヒアリング・ニーズ把握（2-3週目）
**アプローチ方法**:
- 支店でのゆっくりとした対面面談（90分）
- 配偶者同席を推奨
- 安心感を重視した丁寧な説明

**ヒアリング項目**:
1. 退職金額・受取時期
2. 公的年金額・私的年金の有無
3. 現在の資産状況
4. 月々の生活費・支出
5. 住宅ローン等の負債
6. 健康状態・医療費
7. 趣味・やりたいこと
8. 相続に関する考え
9. 子供・孫への支援計画
10. リスクに対する考え方

**使用ツール・資料**:
- 退職後ライフプランシート
- 家計収支表
- 医療・介護費用シミュレーター
- 相続対策チェックリスト
- リスク許容度診断（保守的版）

**トークポイント**:
```
「○○様、まずは月々の生活費を確認しましょう。
年金収入が月25万円、生活費が月30万円ですと、
毎月5万円の不足が生じますね。

この不足分を補いながら、さらにインフレにも
備える必要があります。

ただし、元本を大きく減らすリスクは
避けたいとのことですので、安定性を重視した
運用方法をご提案いたします。」
```

#### フェーズ3: 提案（4-5週目）
**アプローチ方法**:
- 保守的で安定性重視のプラン提示
- わかりやすい図解・大きな文字
- 複雑な商品は避ける
- 配偶者への説明も丁寧に実施

**提案内容例**:
```
【新NISA活用プラン - 65歳退職者Cさんの場合】

現状分析:
- 退職金: 2,000万円
- 預貯金: 1,000万円
- 公的年金: 月25万円（夫婦合計）
- 月々の生活費: 月30万円
- 不足額: 月5万円

提案: 安全重視プラン

退職金2,000万円の配分:
1. 生活予備費(預金): 500万円(約1年分)
2. 新NISA投資: 1,200万円
3. その他運用: 300万円

新NISA内訳:

つみたて投資枠: 月5万円
- バランスファンド(債券60%/株式40%): 月5万円

成長投資枠: 初年度240万円 → 5年で上限達成
- 高配当株ファンド: 120万円
- REITファンド: 60万円
- 債券ファンド: 60万円

想定リターン: 年3%程度
想定分配金: 年36万円(月3万円相当)

10年後の想定資産:
- 新NISA資産: 約1,550万円
- その他資産: 約800万円
- 合計: 約2,350万円

月々のキャッシュフロー:
- 年金収入: 25万円
- 分配金等: 3万円
- 生活費: △30万円
- 不足分: △2万円
→ 預金から補填(年24万円)
```

**使用ツール・資料**:
- オーダーメイド提案書（大きな文字・図解豊富）
- 安全性重視商品パンフレット
- 分配金シミュレーション
- キャッシュフロー表
- リスク説明資料（わかりやすい版）

**トークポイント**:
```
「○○様の場合、まずは1年分の生活費500万円を
預金として確保します。これで安心です。

そして退職金の一部を、安定性の高い
投資信託で運用します。債券の比率を高めた
バランスファンドを中心に、
大きな値動きを避けた運用を心がけます。

分配金として月3万円程度を受け取りながら、
資産も維持していくイメージです。」
```

#### フェーズ4: クロージング（6-7週目）

いつでもご質問にお答えしますので、

**使用ツール・資料**:

#### フェーズ5: フォローアップ（契約後）

## D. 富裕層（資産1億円以上）

### シナリオ4: 紹介による新規富裕層顧客

#### フェーズ1: 初回接触（1週目）
**アプローチ方法**:
- 紹介者を通じた事前情報収集
- 上席者同行での訪問アポ取得
- プレミアムな提案を予告

**使用ツール・資料**:
- 紹介御礼状
- 富裕層向けサービスガイド
- プライベートバンキング案内

**電話トークスクリプト**:
```
「○○様、△△様（紹介者）からご紹介いただきました、
□□証券の●●と申します。

この度は貴重なお時間をいただき、
誠にありがとうございます。

○○様の資産運用について、新NISA制度を含めた
総合的なご提案をさせていただきたく存じます。

私どもの支店長●●も同席させていただき、
当社のプレミアムサービスについても
ご説明させていただきます。

来週、ご都合のよろしい日時はございますでしょうか。
ご自宅へお伺いすることも可能です。」
```

#### フェーズ2: ヒアリング・ニーズ把握（2-3週目）
**アプローチ方法**:
- 上席者同行での訪問（2-3時間）
- 総合的な資産状況の把握
- 事業・相続・税務ニーズの確認
- 専門家チーム（税理士・弁護士）紹介の提案

**ヒアリング項目**:
1. 総資産状況（金融資産・不動産・事業資産）
2. 事業状況（経営者の場合）
3. 収入構成（給与・配当・不動産収入等）
4. 既存取引金融機関との関係
5. 相続対策の進捗状況
6. 家族構成・後継者の状況
7. 投資経験・運用方針
8. 海外資産の有無

## 全セグメント共通の重要ポイント

### アプローチの基本原則
1. **顧客本位**: 常に顧客の利益を最優先
2. **丁寧な説明**: 専門用語を避け、わかりやすく
3. **リスク説明**: メリットだけでなく、リスクも明確に
4. **長期視点**: 短期的な利益ではなく、長期的な資産形成を提案
5. **継続サポート**: 売って終わりではなく、長期的な関係構築

### 法令遵守事項
- 金融商品取引法の遵守
- 適合性の原則の徹底
- 説明義務の履行
- 書面交付の徹底
- 誤解を招く表現の禁止
- 断定的判断の提供禁止
