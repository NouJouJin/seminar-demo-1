## A. 若年資産形成層（20-30代）

### 顧客プロファイル復習
- 年齢: 25-39歳
- 金融資産: 100-500万円
- 投資期間: 30-40年
- デジタルネイティブ
- リスク許容度: 高

### SBI証券が最適な5つの理由

#### 1. クレカ積立で年間6万円分のポイント還元

**訴求ポイント**:
```
三井住友カード プラチナプリファードなら
クレカ積立で5.0%還元

月10万円積立の場合:
- 年間ポイント: 60,000円分
- 30年累計: 180万円分！

競合の楽天証券(1.0%): 36万円分
差額: 144万円分
```

**トークポイント**:
「○○さんの年齢なら、30年間投資できますよね。
その間、SBI証券なら180万円分のポイントがもらえます。
これは楽天証券の5倍です。

180万円あれば、世界一周旅行も夢じゃありません！」

**具体例**:
```
【28歳会社員Aさんの場合】

投資プラン:
- つみたて投資枠: 月10万円
- 成長投資枠: ボーナス時 年120万円
- 年間投資額: 240万円

クレカ積立ポイント(5.0%):
- つみたて投資枠: 年60,000円分
- 32年間（60歳まで）: 192万円分

実質: 投資しながら192万円もらえる！
```

## B. 中堅資産蓄積層（40-50代）

### 顧客プロファイル復習
- 年齢: 40-59歳
- 金融資産: 500-3,000万円
- 投資期間: 15-25年
- ある程度の投資経験
- リスクとリターンのバランス重視

### SBI証券が最適な5つの理由

#### 1. 退職金運用も見据えたコスト効率

**訴求ポイント**:
```
【退職金2,000万円を運用した場合の手数料比較】

SBI証券（信託報酬0.1%）:
- 20年間の手数料: 約40万円
- 20年後の資産: 約2,920万円（年利3%）

対面証券（信託報酬1.0%）:
- 20年間の手数料: 約400万円
- 20年後の資産: 約2,640万円（年利3%）

差額: 280万円

退職金の大切さを知る世代だからこそ、
手数料で目減りさせるのはもったいない
```

**トークポイント**:
「○○様、10年後に退職金を受け取られますよね。
その退職金、どこで運用されるかもう決めていますか?

対面証券だと、20年で280万円も手数料で消えてしまいます。
今から付き合いのある証券会社を変えておくと、
退職金運用も安心です。」

**具体例**:
```
【52歳会社員Cさんの場合】

現在の資産: 1,500万円
退職金見込: 2,000万円（8年後）
新NISA投資: 月10万円×8年

8年後の状況:
- 新NISA資産: 約1,100万円
- 既存資産: 約1,700万円
- 退職金: 2,000万円
- 合計: 約4,800万円

SBI証券なら手数料最小で、
老後資金5,000万円達成可能！
```

---

## C. シニア資産活用層（60代以上）

### 顧客プロファイル復習
- 年齢: 60-75歳
- 金融資産: 1,000-5,000万円
- 投資期間: 10-20年
- 安全性・安定性重視
- 対面サポート希望傾向

### SBI証券が最適な3つの理由

#### 1. 年金を補完する資産、手数料で減らさない

**訴求ポイント**:
```
【退職金2,000万円を20年運用】

SBI証券（信託報酬0.2%、配当型）:
- 手数料: 約80万円
- 分配金: 年60万円×20年 = 1,200万円
- 20年後残高: 約2,000万円
- 合計受取: 3,200万円

対面証券（信託報酬1.5%、配当型）:
- 手数料: 約600万円
- 分配金: 年50万円×20年 = 1,000万円
- 20年後残高: 約1,400万円
- 合計受取: 2,400万円

差額: 800万円

年金を補完する大切な資産、
手数料で目減りさせるのは
もったいない
```

**トークポイント**:
「○○様、年金だけでは月5万円足りないとおっしゃいましたね。

退職金を運用して、その不足分を補うのは
賢い選択です。

ただ、対面証券だと20年で800万円も
手数料で消えてしまいます。

SBI証券なら、その800万円をご自身で使えます。
お孫さんへのお小遣いもたくさんあげられますよ。」

## D. 富裕層（資産1億円以上）

### 顧客プロファイル復習
- 年齢: 40-70代
- 金融資産: 1億円以上
- 高度な金融知識
- 総合的な資産管理ニーズ

### SBI証券が最適な5つの理由

#### 1. 大きな資産だからこそ、コストの差は歴然

**訴求ポイント**:
```
【1億円を30年運用】

SBI証券（信託報酬0.1%）:
- 手数料累計: 約300万円
- 30年後資産: 約2億3,700万円（年利3%）

対面証券（信託報酬1.0%）:
- 手数料累計: 約3,000万円
- 30年後資産: 約2億700万円（年利3%）
```

## まとめ: セグメント別訴求の鉄則

### 1. 数字で具体的に示す
- 抽象的な説明ではなく、具体的な金額
- 「お得です」ではなく「162万円お得」

### 2. 顧客の立場で語る
- 「当社は...」ではなく「○○様なら...」
- 顧客のメリットを最優先

### 3. 競合との比較を明確に
- 「良い」ではなく「楽天証券より〇〇万円お得」
- 差別化ポイントを明確に

### 4. 不安を解消する
- 顧客の懸念に先回りして対応
- 「でも...」に答える

### 5. アクションを促す
- 「検討してください」ではなく「今すぐ始めましょう」
- 具体的な次のステップを示す
