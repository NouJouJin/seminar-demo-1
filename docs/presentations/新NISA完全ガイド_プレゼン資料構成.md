### 第1章: 新NISAとは？（スライド4-7）

#### スライド4: NISAとは
```
NISA = 少額投資非課税制度
Nippon Individual Savings Account

通常、投資で得た利益には約20%の税金がかかります
↓
NISAを使えば、税金がゼロに！

[図解: 通常課税 vs NISA非課税の比較]
利益100万円の場合
- 通常: 税金20万円 → 手取り80万円
- NISA: 税金0円 → 手取り100万円
```

#### スライド5: 新NISA制度の全体像
```
【新NISA の特徴】

✓ 非課税保有期間: 無期限
✓ 年間投資枠: 360万円
✓ 非課税保有限度額: 1,800万円
✓ 口座開設期間: 恒久化
✓ 売却後の枠の再利用: 可能

[図解: 2つの投資枠]
つみたて投資枠: 年間120万円
成長投資枠: 年間240万円
```

#### スライド16: 投資信託とは？
```
投資信託 = 専門家におまかせ投資

[図解: 投資信託の仕組み]
投資家から資金を集める
↓
専門家（ファンドマネージャー）が運用
↓
株式・債券などに分散投資
↓
運用成果を投資家に分配

メリット:
✓ 少額から始められる
✓ 分散投資が簡単
✓ 専門家が運用
✓ 透明性が高い
```
